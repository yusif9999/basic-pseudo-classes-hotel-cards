# Hotel Room Selection UI

A responsive and interactive hotel room pricing UI built entirely with raw HTML and CSS. This project was developed to solidify core CSS concepts, with a strong emphasis on CSS Pseudo-classes, combinators, and float-based layouts without relying on JavaScript or modern layout systems like Flexbox/Grid.

## 🚀 Features

- **CSS-Only Tooltips:** Interactive information pop-ups triggered by `:hover` states and descendant combinators.
- **Interactive UI Elements:** Buttons utilizing `:link`, `:visited`, `:hover`, `:active`, and `:focus` (with custom outlines for accessibility) pseudo-classes to provide instant user feedback.
- **Advanced Selectors:** Strategic use of `:nth-child()` and `:last-child` pseudo-classes alongside adjacent sibling combinators (`a + span`) to style specific cards and position promotional ribbons dynamically.
- **Float-Based Layout:** A classic responsive card layout achieved through `float`, `clear`, and `min-width`/`max-width` properties.
- **Typography & Icons:** Integrated Google Fonts (Poppins) and FontAwesome icons for a polished, professional look.

## 🛠️ Technologies Used

- **HTML5:** Semantic structuring and table formatting.
- **CSS3:** Positioning (`relative`/`absolute`), box model, pseudo-classes, combinators, and overflow management.

## 📋 What I Learned

This project served as a deep dive into the power of CSS selectors. I successfully implemented complex state changes and UI reveals (like the hidden tooltips) relying strictly on CSS hierarchy and pseudo-classes. It also reinforced my understanding of element positioning and clearing floats in traditional CSS architecture.
